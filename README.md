## Betrieb

Das Repository enthält die fertig gebauten Websites. GitHub Pages veröffentlicht den Hauptbranch ohne Jekyll. Es werden keine Sites-Datenbanken, Uploads, Zugangsschlüssel oder privaten Archivbestände übertragen.

Persönliche Browserdaten von früheren Sites-Adressen werden nicht automatisch übernommen. Die bisherigen Sites bleiben bis zur Freigabe ihrer Abschaltung erreichbar.
